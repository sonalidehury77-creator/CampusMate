# CampusMate — Attendance Management

## Purpose

Phase 12 introduces the student attendance management module.

Students can:

- View overall attendance
- View subject-wise attendance
- View present classes
- View absent classes
- View total classes
- View attendance history
- Identify subjects below the required attendance
- Calculate how many classes they can miss
- Calculate how many consecutive classes are required to reach the target
- Project future attendance
